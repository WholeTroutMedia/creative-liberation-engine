# ATELIER Design Surface (DESIGN.md)

> "A living visual page for design artifacts." — Inspired by threads.net/@mangto and Flipboard's Refero Styles.

## Overview
This document acts as the visual manifest and entry point for the **ATELIER Design Library**. It provides a structured view of all incorporated design assets, patterns, and design systems for AI agents, as mandated by the `IE-IDX-0106` and `IE-IDX-0107` ideation cycles.

## Unified Design Library Structure
The scattered design libraries across legacy V4/V5 imports and V6 design-systems have been aggregated into the singular `ATELIER/design-library` matrix:

- **Flora.ai** (`flora/`) — Flora generative design flows.
- **Framer** (`framer/`) — Interactive component patterns.
- **Framify** (`framify/`) — Frame-based composition.
- **Freepik** (`freepik/`) — Vector assets and illustration libraries.
- **Godly** (`godly/`) — Top-tier web design inspirations.
- **Kling** (`kling/`) — Video/motion generation tests.
- **Lottiefiles** (`lottiefiles/`) — JSON-based vector animations.
- **MagicUI** (`magicui/`) — Premium UI components (React/Tailwind).
- **Mobbin** (`mobbin/`) — Mobile & web app design patterns.
- **Motion** (`motion/`) — Kinetic interaction styles.
- **Quebec-Movie** (`quebec-movie/`) — 2D cinematic layout examples.
- **Relume** (`relume/`) — Wireframe libraries and component kits.
- **Remotion** (`remotion/`) — Programmatic video compositions.
- **RunwayML** (`runwayml/`) — Gen-video experiments and AI aesthetic references.
- **Spline** (`spline/`) — 3D web interactive assets.
- **Screenshots** (`_screenshots/`) — Manual references and captures.

## Design Systems for AI Agents (Refero Styles)
Following the directive from **IE-IDX-0106**, the design system targets AI-first experiences:
- High-contrast, brutalist operational panels (Sentinel).
- Glassmorphism overlays.
- Kinetic, smooth, spring-based interactions for agents.

## Implementation Workflow
All new assets generated via Flora.ai or extracted from references must be documented in the respective library catalog and referenced in this `DESIGN.md` visual page.
