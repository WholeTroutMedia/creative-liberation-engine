## 6. GENRE MODIFIERS

Apply these to any base prompt to shift genre:

### Horror
```
+ low-key lighting, dutch angle, desaturated except for sickly green/amber, 
underexposed by 2 stops, lens distortion at edges, breath visible in cold air, 
something barely visible in the deep background shadows
```

### Sci-Fi
```
+ volumetric blue/white atmospheric haze, practical LED rim lighting, 
holographic interface reflections on face, anamorphic lens flare streaks, 
Villeneuve Blade Runner 2049 color palette, brutalist architecture
```

### Romance
```
+ golden hour warmth, lens flare from natural sunlight, 
shallow depth of field at f/1.2, warm skin tones, 
blooming highlights, 85mm portrait compression, 
Kodak Portra 400 film emulation, soft diffusion filter
```

### Documentary
```
+ handheld camera subtle motion, available light only, 
ungraded natural color, 16mm film grain, intimate close distance, 
observational framing with imperfect composition, 
Frederick Wiseman or Maysles Brothers aesthetic
```

### Noir
```
+ high contrast black and white, venetian blind shadows, 
hard single-source lighting from window, cigarette smoke 
catching light beam, rain on glass reflections, 
1940s production design elements, fedora silhouette
```

## 8. PLATFORM-SPECIFIC SETTINGS

### Midjourney
- Quality: `--q 2` for all cinematic shots
- Stylize: `--s 600-900` (higher = more artistic interpretation)
- Version: `--v 6.1` minimum recommended
- Raw mode: `--style raw` for more photorealistic output

### DALL·E 3
- Prefix prompts with: `"A cinematic photograph, shot on film,"`
- Use natural language descriptions over keyword lists
- Specify camera and lens for best results

### Stable Diffusion / Flux
- Model: Realistic Vision or Juggernaut for photorealism
- CFG Scale: 7-9 for cinematic looks
- Sampler: DPM++ 2M Karras
- Steps: 30-50
