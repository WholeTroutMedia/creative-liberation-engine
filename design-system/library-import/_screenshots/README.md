# Screenshot drops for `design-ingest.mjs`

Place images here in subfolders by source name, e.g. `_screenshots/mobbin/`.

**Naming:** `[component]-[variant]-[source]-[platform].png`  
Example: `auth-magic-link-linear-web.png`

The ingest script scans `tools/design-library/` top-level directories; only dirs that contain image files are useful for ingestion. Catalog-only dirs (Framify JSON) are listed in their own READMEs.
