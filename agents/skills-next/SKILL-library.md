# V6 Next-Gen Skills Library

This library expands legacy skills with enterprise-grade capabilities needed for V6.

## New Skills

- `incident-commander` — multi-service outage diagnosis and coordinated remediation workflows.
- `eval-harness` — automatic benchmark generation and regression scoring for agents/flows.
- `route-governor` — route manifest drift detection and fix recommendations.
- `memory-curator` — deduplication, canonicalization, and retention policy enforcement.
- `security-hardener` — auth boundary checks, secret surface scans, and hardening patch guidance.
- `cost-arbitrage` — model routing optimization by latency/cost/quality envelopes.
- `workflow-synthesizer` — merges overlapping workflows into normalized execution graphs.
- `skills-linter` — validates skill metadata, callable flags, and constitutional references.
- `agent-observability` — traces agent runs, failure buckets, and quality telemetry summaries.
- `migration-operator` — controlled capability migration from legacy versions to V6 contracts.

## Adoption Rule

No new operational skill should launch without:

- registry entry
- quality/eval criteria
- fallback behavior
- explicit ownership
