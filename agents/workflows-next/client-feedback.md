# client-feedback

## Purpose

Automate the aggregation, synthesis, and actionable task generation derived from client communications and video feedback platforms.

## Steps

1. Ingest client feedback (via emails, Frame.io comments, or direct webhook).
2. Synthesize feedback sentiment and classify by severity/priority.
3. Automatically generate sub-tasks for targeted agents (e.g., color correction, audio mix, editing).
4. Update the project timeline and notify the lead producer.
5. Provide a summary digest report to stakeholders via preferred comm channel.
