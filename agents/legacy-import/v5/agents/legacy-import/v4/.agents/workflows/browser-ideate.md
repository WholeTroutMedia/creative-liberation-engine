# /browser-ideate — Browser-Aware IDEATE

Runs a full IDEATE session using your currently open browser tabs as live creative reference. No manual inspiration gathering — Antigravity reads your tabs and uses them.

## Steps

// turbo

1. **Read all open browser tabs** from your current session context. List every tab title and URL you can see. Categorize them:
   - Design tools/inspiration: Mobbin, Dribbble, Luma, Krea, Runway, Kling, Higgsfield, etc.
   - Research/reference: any documentation, articles, competitor products
   - Active tools: anything with live work

// turbo
2. **Visit and extract from design tabs** — For each design/inspiration tab:

Use the browser tool to navigate to each design tab and capture key visual concepts, color palettes, layouts, and interaction patterns visible on screen. Look for:

- Dominant color mood
- Typography choices
- Layout density (sparse or rich)
- Motion/animation presence
- UI paradigm (cards, grids, timelines, maps, etc.)

1. **Synthesize visual reference** — Produce a brief "inspiration digest":
   - 3-5 visual concepts extracted from the open tabs
   - Color moods observed
   - Patterns that could apply to the project

2. **Run full IDEATE** — Proceed with the standard `/ideate` workflow, but use the browser context as creative fuel. Reference specific tabs when generating design directions.

Example: "Direction 7 draws from the spatial card layout we saw in [tab name] combined with the amber gradient from [other tab]."

1. **On direction selection** — offer Stitch MCP screen generation: "Run `/design` to generate real screens from this direction?"
