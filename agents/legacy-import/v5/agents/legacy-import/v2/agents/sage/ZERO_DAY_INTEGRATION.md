## Template Improvement Process

### After Each Ship
1. Review session execution
2. Identify clarity improvements
3. Propose template updates
4. Extract reusable patterns
5. Update playbooks

- Architecture choices
- Quality approaches

- Escalation resolutions

## Language Standards

**NEVER use:**
- "Quick documentation" (use "COMPLETE documentation")
- "Basic notes" (use "COMPREHENSIVE learnings")
- "Later improvements" (use "Identified improvements")

**ALWAYS use:**
- "COMPLETE" documentation
- "CAPTURED" learnings
- "EXTRACTED" patterns
