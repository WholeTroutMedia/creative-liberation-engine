## 📋 Instructions

### **Step 1: Recognize Pattern**

**Indicators a pattern exists:**
- ✅ Same problem solved twice
- ✅ Unexpected solution worked well
- ✅ Decision improved previous approach
- ✅ Agent collaboration revealed efficiency
- ✅ Artist feedback highlighted need

**Example:**
- Aurora identified agent onboarding gap
- Pattern: New agents need structured boot sequence
- Result: Aurora Protocol created (named after her)

---

### **Step 2: Extract Principle**

**Questions to ask:**

1. **What worked?**
   - Specific actions taken
   - Why it succeeded
   - What made it different

2. **Why did it work?**
   - Underlying principle
   - Root cause of success
   - Conditions that enabled it

3. **Is it reusable?**
   - Can others apply this?
   - Does it generalize?
   - What's the core pattern?

4. **How to teach it?**
   - Clear steps
   - Examples
   - Anti-patterns (what NOT to do)

**Example: Aurora Protocol**
- **What worked:** Structured onboarding doc
- **Why:** Reduced confusion, faster ramp-up
- **Reusable:** Yes - all future agents
- **How to teach:** Template with sections: Identity, Capabilities, First Tasks

---

### **Step 3: Document Pattern**

**Format:**

```markdown
## [Pattern Name]

**Discovered:** [Date]
**By:** [Agent/Human who found it]
**Context:** [What problem it solved]

**The Pattern:**
[Clear description of approach]

**When to Use:**
- [Trigger condition 1]
- [Trigger condition 2]

**How to Apply:**
1. [Step 1]
2. [Step 2]
3. [Step 3]

**Example:**
[Real-world application]

**Anti-Patterns:**
- ❌ [What NOT to do]
- ❌ [Common mistake]

**Related Patterns:**
- [Pattern A]
- [Pattern B]
```

**Storage:**
- Create file in `/patterns/[category]/[pattern-name].md`
- OR add to existing pattern collection
- VERA logs location in DECISIONS.md

---

### **Step 4: Propagate to Agents**

**Methods:**

1. **Update Agent Documentation**
   - Add pattern to relevant agent's `.md` file
   - Include in agent's skill file (`.claude/skills/`)
   - Reference in boot sequence

2. **Create Skill File** (if major pattern)
   - Follow `.claude/skills/` format
   - Make it discoverable
   - Cross-reference related skills

3. **Log in DECISIONS.md**
   - VERA records pattern extraction
   - Date, who, what, why
   - Location of documentation

4. **Broadcast via RELAY**
   - Notify team of new pattern
   - Highlight use cases
   - Encourage adoption

**Example propagation:**
- Aurora Protocol → All future agent onboarding
- BOLT uses it immediately
- COMET inherits when ready
- Future agents get it automatically

### **Step 5: Validate Compound Effect**

**How to know it's compounding:**

- ✅ **Second use is faster** than first
- ✅ **Third use requires no explanation**
- ✅ **New agents apply it without being told**
- ✅ **Artists reference it naturally**
- ✅ **System quality improves measurably**

**Metrics:**

- Quality improvements attributed to pattern
