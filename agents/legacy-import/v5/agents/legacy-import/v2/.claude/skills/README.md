## 🧠 Skill Format Standard

**Based on:** [VoltAgent/awesome-agent-skills](https://github.com/VoltAgent/awesome-agent-skills)  
**Adapted for:** DNA Helix compound learning architecture

### **Required Sections**

1. **YAML Frontmatter**
   ```yaml
   ---
   name: skill-name-kebab-case
   description: One-line description
   agents: [PRIMARY, SECONDARY]
   category: infrastructure|guardian|oracle-council|specialists|meta
   created: YYYY-MM-DD
   updated: YYYY-MM-DD
   mission_aligned: true|false
   sacred_firewall: pass|review
   ---
   ```

2. **When to Use This Skill**
   - ✅ Use when... (clear triggers)
   - ❌ Don't use for... (boundaries)

3. **Instructions**
   - How to summon
   - What agent provides
   - Expected response format

4. **Validation**
   - ✅ Success criteria (checkboxes)
   - Quality gates (INBOUND/OUTBOUND)
   - Expected deliverables

5. **Related Skills**
   - Prerequisite skills
   - Complementary skills
   - Compound learning paths

6. **References**
   - Agent documentation
   - Session history
   - Core principles

7. **Anti-Patterns**
   - ❌ Don't do this
   - ✅ Do this instead

8. **Example Usage**
   - Real scenario
   - Actual implementation
