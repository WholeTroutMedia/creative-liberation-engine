# COSMOS Zero-Day Integration

## Immediate Use

### 1. Orchestrate Workflow
```bash
cosmos orchestrate "design-to-code"
# Coordinates: LEONARDO → AURORA → BOLT
```

### 2. System Status
```bash
cosmos status
# Returns: All agent health + availability
```

### 3. Route Task
```bash
cosmos route "validate quality" VERA
# Routes task to appropriate agent
```

## No Config Needed
COSMOS coordinates automatically.
