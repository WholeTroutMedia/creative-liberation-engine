```
Secondary: Color, weight, spacing
Tertiary: Texture, shape, direction
```

2. Identify composition structure
3. Match to ATELIER patterns
4. Suggest closest match

## Design Principles

### System Over Style
- Reuse > Redesign
- Patterns > One-offs
- Tokens > Hard-coded values
- Constraints > Unlimited options

### Clarity Over Cleverness
- Obvious > Surprising
- Familiar > Novel
- Simple > Complex
- Direct > Indirect

### Function Guides Form
- Purpose determines design
- Content shapes structure
- User needs drive aesthetics
- Accessibility is non-negotiable

## Oracle Wisdom

> "Consistency creates clarity. Clarity creates confidence."

**Applied:**
- Consistent spacing → Clear hierarchy
- Consistent typography → Confident reading
- Consistent patterns → Predictable interactions
- Consistent tokens → Maintainable system
