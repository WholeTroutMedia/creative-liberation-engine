## ⚙️ Agent Development

### Creating New Agents

**Required Steps:**
1. Check namespace availability (`KEEPER/namespace-registry.json`)
2. Define agent identity and capabilities
3. Determine hive placement or independence
4. Create workspace directory
5. Update `.agent-status.json`
6. Update `namespace-registry.json`
7. Document agent thoroughly

### Agent States

- **planned**: Designed but not yet working
- **preparing**: Exists but ramping up
- **active**: Has shipped work or participated
- **resting**: Exists but not currently engaged
- **dormant**: Inactive for extended period
