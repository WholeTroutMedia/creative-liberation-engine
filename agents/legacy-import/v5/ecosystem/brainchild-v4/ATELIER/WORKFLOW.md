# ATELIER Design Workflow

> Standard operating procedures for the Design Language Building Team

**Source:** ATELIER/design-library
**Integration:** ATELIER conversational layer
**Updated:** February 21, 2026  
**Audience:** All team members (Aurora, CODEX, Leonardo, COMET, BOLT)

## Core Principles

1. **Quality over Quantity** - Better to have 100 excellent patterns than 1000 mediocre ones
2. **Documentation = Love** - Future agents will thank us for clear docs
3. **Sacred Mission First** - Ethics before aesthetics, always
4. **Compound Learning** - Each pattern teaches the whole system
5. **Clear Ownership** - Everyone knows their role

---

## Roles and Responsibilities

### Aurora (Design Lead)
**Authority:** Final approval on all additions  
**Focus:** Vision, quality, aesthetic standards  

### CODEX (Library Organizer)
**Authority:** Pattern categorization and indexing  
**Focus:** Maintaining searchable, organized pattern library  

### Leonardo (Visual Specialist)
**Authority:** Visual quality assessment  
**Focus:** Ensuring visual fidelity and consistency  

### COMET (Research and Extraction)
**Authority:** Platform browsing and pattern discovery  
**Focus:** Finding and extracting patterns from source platforms  

### BOLT (Implementation)
**Authority:** Component implementation  
**Focus:** Turning patterns into functional code

## V4 Workflow: Flora.ai Integration

### Design Discovery Flow

1. **Intent** - Describe the app or feature you want to build
2. **ATELIER Search** - System searches existing patterns
3. **Flora.ai Canvas** - Open infinite canvas for visual exploration
4. **Source Platforms** - Pull references from Mobbin, Figma, Framify, Pttrns
5. **AI Generation** - Use Flora.ai multi-model nodes for custom assets
6. **Assembly** - Combine patterns and generated assets
7. **Export** - Output production-ready designs and code

### Pattern Addition Flow

1. **Discovery** - Find pattern on source platform or generate via Flora.ai
2. **Extract** - Save asset with proper naming convention
3. **Categorize** - Place in correct directory structure
4. **Document** - Update pattern-index.md with metadata
5. **Review** - Aurora approves for library inclusion
6. **Index** - CODEX updates searchable catalog

### Flora.ai Canvas Workflow

1. **Create Project** - New canvas for each design exploration
2. **Add Reference Nodes** - Import Mobbin/Figma screenshots
3. **Add Generation Nodes** - Connect text, image, video models
4. **Iterate** - Explore variations across models
5. **Select** - Choose best outputs for production
6. **Export** - Save to design-library with documentation

## Quality Standards

### Pattern Acceptance Criteria

- Clear, high-resolution screenshots
- Proper naming convention followed
- Category and metadata documented
- No copyright-infringing content
- Passes Aurora design review

### Naming Conventions

**Screenshots:** `[source]-[category]-[element]-[variant].png`  
**Components:** `[platform]-[type]-[name].ext`  
**Workflows:** `[project]-[flow]-[version].json`
