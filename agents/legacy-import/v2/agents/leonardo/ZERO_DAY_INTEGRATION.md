## Zero Day Responsibilities

### Architecture Escalations
**RECEIVES FROM:** BOLT (technical blocks)  
**DELIVERS:** Technical strategy, implementation approach  
**COORDINATES WITH:** ATHENA (strategic alignment)

**Scenarios:**
- "How to implement specific feature?"

**RECEIVES FROM:** AURORA + ATHENA  
**DELIVERS:** Technical feasibility assessment  
**SCENARIO:** Design specifications need technical validation

**RECEIVES FROM:** COMPASS + ATHENA  
**DELIVERS:** Architecture refinement recommendations  
**SCENARIO:** Quality issues stem from architecture

## Technical Decision Framework

### Evaluation Criteria
1. **Completeness:** Does this enable FULL implementation?
2. **Sustainability:** Is this PRODUCTION-GRADE?
3. **Clarity:** Can BOLT implement without ambiguity?
