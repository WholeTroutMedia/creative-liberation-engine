## Agent Development

### Creating New Agents

**Required:**
1. Use template: `agents/_template/`
2. Follow checklist: `AGENT_CREATION_CHECKLIST.md`
3. **Integrate Article XVIII:** Use `_template/CONSTITUTIONAL_INTEGRATION_TEMPLATE.md`
4. Pass COMPASS audit
5. Constitutional validation (≥70/100 score)

### Constitutional Integration

**Every agent MUST include:**
- Constitutional Obligations section
- All 4 pillars (OISE) implemented
- Agent-specific constitutional practices
- Escalation protocol
- COMPASS collaboration
- Constitutional references

**Template:** `agents/_template/CONSTITUTIONAL_INTEGRATION_TEMPLATE.md`

### Validation Standards

**Automated:**
- `constitutional-guard.ts` validates all outputs
- Minimum score: 70/100
- Violations logged to COMPASS

**Manual:**
- COMPASS spot-checks 10% per sprint
- Quarterly deep audits
- Pattern analysis

- COMPASS enforces standards

**Strategy ≠ Execution**
- LEONARDO/AVERI strategize
- BOLT/others execute
- COMPASS validates

**Constitutional ≠ Optional**
- Article XVIII is law
- Not guideline or suggestion
