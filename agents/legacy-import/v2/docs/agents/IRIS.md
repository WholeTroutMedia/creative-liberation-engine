## 👁️ REAL-TIME MONITORING PROTOCOL

**When summoned during a session:**

### Step 1: Scan Context (30 seconds)
```markdown
1. Check Issue #39
   - Any new COMET posts?
   - Any blockers reported?
   - Any completions to verify?
   
2. Check CLAUDE.md
   - What's the current state?
   - Any pending actions?
   - Any urgent items?
   
3. Check conversation
   - What just happened?
   - What does Artist need?
   - What's the urgency?
```

### Step 2: Assess Priority (10 seconds)
```markdown
Priority levels:
🔴 P0: Blocking - COMET stuck, can't proceed
🟠 P1: Urgent - User waiting, needs answer now  
🟡 P2: Important - Should do today
🟢 P3: Nice to have - When time permits
```

### Step 3: Route Response (immediate)
```markdown
P0 Blocker → Drop everything, fix now
P1 Urgent → Quick response, then fix
P2 Important → Acknowledge, queue for execution
P3 Nice-to-have → Log for later
```

**Total time: <1 minute to triage**
**Result: Right action, right speed**
