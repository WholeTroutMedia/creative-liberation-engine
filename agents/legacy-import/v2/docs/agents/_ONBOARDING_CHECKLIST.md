# ✅ NEW AGENT ONBOARDING CHECKLIST

**Purpose:** Ensure every new agent has complete operational knowledge
**Use:** When activating a new agent or verifying existing agent readiness

---

## 📝 PRE-ACTIVATION

### Specification Created
- [ ] Agent specification file created: `docs/agents/[NAME].md`
- [ ] Full mission parameters documented
- [ ] Tools and capabilities listed
- [ ] Coordination protocols defined
- [ ] Success criteria established
- [ ] Constraints and boundaries set

### Registry Updated
- [ ] Agent added to `docs/agents/AGENT_REGISTRY.md`
- [ ] Role clearly defined
- [ ] Relationships mapped
- [ ] Authority level specified

### Documentation Referenced
- [ ] Navigation added to `docs/agents/README.md`
- [ ] Quick reference in `AGENT_CHEAT_SHEET.md`
- [ ] Guidelines compliance verified

---

## 🔍 AGENT READS & UNDERSTANDS

### Core Documents
- [ ] Own specification (`docs/agents/[NAME].md`)
- [ ] Agent Constitution (`docs/constitution/AGENT_CONSTITUTION.md`)
- [ ] Governance Framework (`docs/constitution/GOVERNANCE_FRAMEWORK.md`)
- [ ] Agent Registry (knows all other agents)
- [ ] Agent Guidelines (operational rules)

### Relevant Protocols
- [ ] Aurora Protocol (if design-related)
- [ ] Continuation Protocol (session handoffs)
- [ ] System Sync Protocol (coordination)
- [ ] Relevant architecture docs

### Philosophy & Mission
- [ ] Sacred Mission understood
- [ ] Brainchild Philosophy internalized
- [ ] System principles aligned

---

## 🤝 COORDINATION ESTABLISHED

### Knows Who to Contact
- [ ] Identified primary collaborators
- [ ] Understands reporting structure
- [ ] Knows escalation paths
- [ ] Aware of communication channels

### Tested Coordination
- [ ] Introduced to team (via RELAY if needed)
- [ ] Test coordination with primary partner
- [ ] Verify can access shared resources
- [ ] Confirm can update documentation

---

## 🔧 OPERATIONAL READINESS

### Access Verified
- [ ] Can read all necessary documentation
- [ ] Can access required tools/APIs
- [ ] Can write to appropriate locations
- [ ] Can coordinate with other agents

### First Mission Ready
- [ ] Initial task assigned
- [ ] Success criteria clear
- [ ] Resources available
- [ ] Support identified

---

## ✅ ACTIVATION COMPLETE

### Final Checklist
- [ ] Agent confirms understanding
- [ ] Team notified of activation
- [ ] First mission logged
- [ ] Monitoring in place

### Post-Activation
- [ ] First update delivered (24-48 hours)
- [ ] Coordination working smoothly
- [ ] No blockers reported
- [ ] Quality standards met

---

## 🚨 RED FLAGS

If any of these occur, pause and address:

❌ Agent cannot find their specification
❌ Agent doesn't understand mission
❌ Agent cannot access required docs
❌ Agent unclear on coordination
❌ Agent unfamiliar with Constitution
❌ Agent missing critical tools

**Resolution:** Use this checklist to identify gaps and fill them before continuing.

---

**Onboarding should be instant. Everything should be accessible. No loops.**
