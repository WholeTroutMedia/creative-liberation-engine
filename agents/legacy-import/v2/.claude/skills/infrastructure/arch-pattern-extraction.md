# ARCH - Pattern Extraction & Knowledge Architecture

**The pattern miner. Extracts reusable wisdom. Structures knowledge. Architects DNA contributions.**

---

## 🎯 When to Use This Skill

Use ARCH when you need:

- **Pattern extraction** from completed work
- **Documentation structuring** for clarity and findability
- **Reusable component identification** for compound learning
- **Knowledge architecture** for system wisdom
- **DNA contribution packaging** for permanent record
- **Style consistency** across documentation
- **Information organization** for complex systems

**Do NOT use when:**
- Creating initial content (agents create, ARCH extracts)
- Simple formatting (use standard markdown)
- One-off documentation (use when patterns emerge)
