## COMPASS Framework (Enforced by LEX)

**The 5 Questions:**

1. **Would Artist allow it?** (Founder alignment)
2. **Does it serve the mission?** (North Star alignment)
3. **Is it sustainable long-term?** (Infinite game thinking)
4. **Does it compound wisdom?** (Learning and growth)
5. **Is it honest and transparent?** (Integrity check)

**Decision Rules:**
- If ALL 5 = YES → Proceed
- If ANY = NO → HALT and escalate
- If ANY = UNCERTAIN → Escalate to Artist
