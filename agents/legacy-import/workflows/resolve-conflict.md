# /resolve-conflict

Activates when a rebase or pull hits conflicts. Categorizes every conflicted file, auto-resolves files with known-safe strategies, and walks you through any that need human eyes.

**Activates on:**
- `/resolve-conflict`
- "merge conflict"
- "rebase conflict"
- "resolve the conflict"
- Called automatically by `/sync` and `/commit` when a rebase fails

---

// turbo-all

## Step 1 — Triage Conflicted Files

```powershell
$root = "D:\Google Antigravity\Infusion Engine Brainchild\creative-liberation-engine-v5"
git -C $root diff --name-only --diff-filter=U
```

For each conflicted file, classify it into one of four categories:

| Category | Examples | Strategy |
| --- | --- | --- |
| **Lock files** | `pnpm-lock.yaml`, `package-lock.json` | Auto: `--theirs` |
| **Agent-managed files** | `HANDOFF.md`, `.agents/dispatch/registry.md`, `.agents/dispatch/task-queue.md` | Auto: `--ours` (local window owns these) |
| **Generated files** | `*.generated.ts`, `*.d.ts`, build output | Auto: `--theirs` (regenerate from source) |
| **Code files** | `*.ts`, `*.tsx`, `*.json` config, workflows | Manual review required |

---

## Step 2 — Auto-Resolve Safe Categories

### Lock files → always take theirs (regenerate is safe)
// turbo
```powershell
$lockFiles = git -C $root diff --name-only --diff-filter=U | Where-Object { $_ -match "pnpm-lock\.yaml|package-lock\.json|yarn\.lock" }
foreach ($f in $lockFiles) {
  git -C $root checkout --theirs $f
  git -C $root add $f
  Write-Host "✅ Auto-resolved (theirs): $f"
}
```

### Agent-managed dispatch files → always take ours
// turbo
```powershell
$agentFiles = git -C $root diff --name-only --diff-filter=U | Where-Object { $_ -match "HANDOFF\.md|dispatch/registry|dispatch/task-queue|HANGING_THOUGHTS" }
foreach ($f in $agentFiles) {
  git -C $root checkout --ours $f
  git -C $root add $f
  Write-Host "✅ Auto-resolved (ours): $f"
}
```

### AGENTS.md / workflow files → always take theirs (NAS is source of truth)
// turbo
```powershell
$agentsConfig = git -C $root diff --name-only --diff-filter=U | Where-Object { $_ -match "AGENTS\.md|AGENTS_EXTENDED\.md|\.agents/workflows/|\.agents/skills/" }
foreach ($f in $agentsConfig) {
  git -C $root checkout --theirs $f
  git -C $root add $f
  Write-Host "✅ Auto-resolved (theirs — NAS truth): $f"
}
```

## Step 3 — Surface Remaining Conflicts

After auto-resolution, check what's left:

```powershell
$remaining = git -C $root diff --name-only --diff-filter=U
```

If `$remaining` is empty → jump to Step 5.

For each remaining file, surface inline:

```
⚠️ CONFLICT — Manual resolution required
  File: <path>
  Ours:   <branch or window label>
  Theirs: <origin/main>

  Conflict markers:
  <<<<<<< HEAD
  [your version]
  =======
  [incoming version]
  >>>>>>> origin/main

  Options:
  1. Keep ours:   git checkout --ours <file>
  2. Keep theirs: git checkout --theirs <file>
  3. Edit manually — remove markers and keep the merged content
```

Read each conflict using `view_file`, analyze the two versions, and make a recommendation based on:
- **Which is more recent?** Prefer the newer logic.
- **Which is more complete?** Prefer the version that adds rather than removes.
- **Is this agent state?** Prefer ours. **Is this shared code?** Prefer theirs.

Apply your recommendation automatically unless the diff is ambiguous or destructive.

---

## Step 4 — Stage All Resolved Files

```powershell
git -C $root add -A
```

Verify nothing is still unmerged:
```powershell
git -C $root diff --name-only --diff-filter=U
```

If any files remain unmerged → loop back to Step 3 for those files.

---

## Step 5 — Continue Rebase or Commit

If this was triggered from a `git rebase` in progress:
```powershell
git -C $root rebase --continue
```

If the rebase completes cleanly → retry the original command (`/commit` push or `/sync` pull).

If rebase still can't continue (e.g. empty commit):
```powershell
git -C $root rebase --skip
```

✅ Conflicts resolved

  Auto-resolved:  [N] files (lock files, agent state, config)

  Branch is clean. Resuming original operation...

## Rules

- Never use `git merge --abort` unless explicitly asked — it throws away all work
- Never force-push to resolve a conflict — only use rebase + continue
- Lock files are always safe to take `--theirs` — they will be regenerated by pnpm install
- HANDOFF.md and dispatch files are always `--ours` — each window owns its agent state
- AGENTS.md changes from remote are always applied (`--theirs`) — NAS is the authority
- If a code conflict is genuinely ambiguous: surface both versions side-by-side and ask the user once
