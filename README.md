# Creative Liberation Engine V6

`creative-liberation-engine` is the clean-root successor to `creative-liberation-engine-v5`.

## Operating Boundary

- `creative-liberation-engine` is the only write target for V6 planning and build-out.
- `creative-liberation-engine-v5` is reference-only unless an explicit extraction or backport is requested.
- New structure must be contract-first and anti-scatter by default.

## Root Layout

- `docs/` - contracts, architecture, decisions, and phase documents
- `schemas/` - machine-checkable schemas for routes, memory, heritage, and future contracts
- `inventory/` - V1-V5 heritage baseline, salvage backlog, and capability census
- `wiki/` - wiki projection rules and note templates
- `packages/`, `apps/`, `services/` - future implementation surfaces
- `runtime/` - runtime manifests and operational composition
- `tests/` - contract, integration, and migration validation
- `tools/` - migration and maintenance utilities

## Current Phase

Phase 0: clean skeleton and canonical contracts.
